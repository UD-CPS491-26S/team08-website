Geospacial Embedding Projector

Team 08 Capstone Project

Project Overview

      This project focused on developing a web-based visualization tool that integrates geospatial data with dimensional and time-based embeddings. The work was completed in collaboration with Riverside Research and supported by their SWAT (Software Applications Team), which emphasizes rapid prototyping, design thinking, and agile development practices. The team also worked closely with Chad Korbecki and Wes Baldwin throughout development.

      The core challenge addressed in this project was the disconnect between embedding visualization tools and geospatial mapping systems. While existing embedding tools allow users to explore patterns and clusters in high-dimensional space, they do not effectively connect those patterns to real-world geographic locations. This limits the ability of analysts to interpret how spatial and temporal relationships appear within the data.

      To solve this, the team developed a full-stack application that links embedding visualizations with an interactive map and a timeline filtering system. The final product allows users to select data points on a map and immediately view their corresponding positions in embedding space, and vice versa. A synchronized timeline enables filtering across both views, ensuring all components update consistently as time progresses.

      By the end of the semester, the team delivered a fully functional system that demonstrates this integration. The application includes a customized embedding visualization tool, a performant mapping interface, and a backend capable of handling filtered data queries. While some limitations remain particularly in large-scale performance the final product successfully meets the primary project objectives and provides a strong foundation for future expansion.
